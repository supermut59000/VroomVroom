VroomVroom — Politique de confidentialité

Dernière mise à jour : 3 novembre 2026 · Application fr.ouiouibaguette.vroomvroom

VroomVroom est une application de suivi de carburant (consommation, coûts, E85/flexfuel) et de maintenance de véhicules. Cette page explique quelles données l'application traite, pourquoi, et comment vous gardez le contrôle.

1. Données traitées par l'application

L'application ne propose pas de compte et ne collecte aucune donnée « sur vous » en dehors de ce que vous saisissez volontairement :

  • Informations véhicules : marque, modèle, année, plaque d'immatriculation, type de carburant, capacité du réservoir, date/prix d'achat, suivi d'assurance kilométrique, compteur, description ;
  • Entrées de carburant : date, compteur kilométrique, litres, prix, station (nom facultatif), type de carburant (E10, SP98, E85, diesel, GPL) ;
  • Entrées de maintenance : date, kilométrage, type, coût, notes ;
  • Paramètres E85 : date de conversion, coût du kit, surconsommation estimée, pourcentage cible ;
  • Position GPS (facultative) : uniquement lorsque vous utilisez un bouton « position actuelle » (liste des stations proches, localisation d'un plein) ou activez l'alerte de démarrage à froid sur un lieu donné ;
  • Paramètres de l'application : mode de stockage des données, préférences d'affichage.

2. Où vos données sont stockées

  • Mode local (par défaut) : toutes vos données restent uniquement sur votre appareil (stockage local du système, IndexedDB). Rien n'est envoyé sur aucun serveur de notre part.
  • Mode serveur (option avancée) : si vous le configurez, vos données sont stockées sur votre propre serveur (votre infrastructure), avec une clé d'API que vous générez. Nous n'avons alors aucun accès à vos données.

Les données ne sont jamais vendues, louées ni utilisées à des fins de publicité.

3. Services tiers consultés (et données envoyées)

Pour certaines fonctionnalités, l'application interroge des services tiers. Seules les données strictement nécessaires à la requête sont transmises, jamais de données personnelles :

L'application ne contient aucun analytics, aucun pixel publicitaire, aucun SDK de suivi tiers (pas de Firebase, Google Analytics, etc.).

4. Données sensibles

L'application ne traite aucune donnée sensible au sens du RGPD (santé, opinions, données biométriques…). La position géographique est un donnée facultative, utilisée uniquement pour les fonctions décrites au §3, et jamais stockée hors de votre appareil (mode local) ou de votre serveur (mode serveur).

5. Mineurs

L'application n'est pas destinée aux enfants de moins de 13 ans et ne cherche pas à collecter leurs données.

6. Durée de conservation et vos droits

  • En mode local, vos données restent sur votre appareil tant que vous les conservez : vous pouvez les modifier, exporter (CSV) ou supprimer à tout moment, entrée par entrée, par véhicule, ou en réinitialisant l'application (réinstall / stockage app).
  • En mode serveur, les données sont conservées sur votre serveur ; vous en avez l'intégralité du contrôle (export, suppression, suppression du serveur).
  • Pour toute demande (accès, rectification, suppression, portabilité), contactez-nous à l'adresse ci-dessous ; nous y répondrons sans délai injustifié.
